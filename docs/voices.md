# Voice configuration

All narration is generated by [ElevenLabs](https://elevenlabs.io) with **your own account and API key**.
This repository stores only voice IDs (`config/voices.json`). It ships no voice models and no recorded voices.

**The voice is used exactly as ElevenLabs delivers it.** The pipeline sends no voice settings (each voice keeps its own
default speed, stability and style) and never changes the audio: no speed-up or slow-down, no pause shortening or
insertion, no pitch or emphasis edits, no EQ or compression. Each scene is one request, with the neighbouring scenes sent
as `previous_text`/`next_text` so the read flows naturally across cuts. The only edit is cutting the silence before the
first word and after the last. Whisper listens to every take; if it mishears the script, the scene is requested again
with a new seed and the clearest take is kept. Loudness is evened out for the final mix (level only).

## Use your own ElevenLabs account, step by step

1. **Create an account.** Sign up at [elevenlabs.io](https://elevenlabs.io). The free plan is enough to test; check
   ElevenLabs' current pricing and licence terms for commercial use.
2. **Find voices.** In the ElevenLabs app open **Voices**. *Default voices* are available at once. *Voice Library*
   voices are made by the community: open one and choose **Add to My Voices** before the API can use it.
3. **Choose a voice.** Play its preview. For short vertical videos pick a clear voice that stays intelligible at a brisk pace.
4. **Get the voice ID.** In **My Voices**, open the ⋯ menu on the voice and choose **Copy voice ID**. It is 20 letters and digits.
5. **Create an API key.** Open **Developers → API keys → Create key**. The key needs access to *Text to Speech*, *User (read)* for the credit counter, and
   *Voices (read)*. Copy it once; ElevenLabs does not show it again.
6. **Give the key to the project.** Run `python3 video.py voices key` in your own terminal (hidden input; checked, then saved to `.env`), or put
   `ELEVENLABS_API_KEY=...` in `.env` yourself. `.env` is git-ignored.
7. **Set the voice in the project.** `python3 video.py voices add <voice id> --name "My voice"`. It confirms with ElevenLabs that
   your account can use the voice and adds it to `config/voices.json`.
8. **Generate sample audio.** `python3 video.py voices test "A line to hear" --voice <key>` saves an mp3 in `output/voice-tests/`. This uses about one credit
   per character. The **Preview** buttons play ElevenLabs' free sample instead.
9. **Replace the default voice.** `python3 video.py voices use <key>`. From then on every new video uses it.

To pin a different voice for one language, set it in `config/voices.json`:

```json
"languages": { "en": null, "hi": "sarah", "hl": "sarah" }
```

`null` means "use the final voice". For Hindi and Hinglish, choose a voice that sounds natural in Hindi: test it first.

### Voices inside a storyboard

A storyboard can override the narrator: top-level `"hosts": ["george"]` (several entries alternate by scene), a scene's
`"narrator"`, or a character's `"voice"` in the character-story style. Each value is a registry key, a voice name, an
ElevenLabs voice ID, or `elevenlabs:<voice ID>`.

## How credits are used

One credit per character sent. Takes are cached in `output/.cache/elevenlabs`, so re-rendering the same script costs
nothing. Every mode makes one take per scene; max (up to 3) and cinematic (up to 5) request a scene again only when
Whisper mishears it, so most videos use about the script's length in credits.

## Troubleshooting

| Message or symptom | Cause | Fix |
|---|---|---|
| `ELEVENLABS_API_KEY is missing` | No key in `.env` | Add it to `.env` or run `python3 video.py voices key` |
| `ElevenLabs 401` / "Key not accepted" | Key mistyped, revoked, or missing the Text to Speech permission | Create a new key with Text to Speech and Voices access |
| `voice_not_found` | The voice ID is not in your account | Add the Voice Library voice to My Voices, or check the ID |
| `quota_exceeded` | Out of credits for this billing period | Wait for the reset, upgrade, or shorten the script |
| `ElevenLabs 429` | Too many requests at once | The pipeline retries by itself; if it persists, wait a minute |
| Voice sounds rushed or slow | That is the voice's own pace | Pick another voice: `python3 video.py voices use <key>` (the pipeline does not change speed) |
| Wrong pronunciation of a name | The model guessed | Add `"say": {"Name": "how-to-say-it"}` to the scene in the storyboard |
| Hindi sounds accented | The chosen voice is English-first | Pin a different voice for `hi`/`hl` under `languages` |

## Responsible use

Use only voices you have the right to use. Do not clone a real person's voice without their consent. Follow
ElevenLabs' terms, including their rules on disclosure and commercial use.
